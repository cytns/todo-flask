# Todo Flask

Простое веб-приложение для управления задачами.

Пользователь может:

- добавлять задачи
- отмечать задачи как выполненные
- удалять задачи

## Стек

Frontend:

- HTML
- CSS

Backend:

- Python
- Flask

БД:

- SQLite

## Запуск проекта

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```
